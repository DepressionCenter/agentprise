      Help
      
        
      Why are there so many formats?
      
        
      Each AI product stores agents its own way. Microsoft uses two different files, Gemini and Claude share one open standard, and ChatGPT has no file at all. Agentprise keeps one description and writes each format for you.
      
        
      Which one do I need?
      
        
      Keep the complete copy. It also uploads to Gemini and Claude. Add the .agent file for Teams chats, or the Copilot app package for the Agents list in the Copilot app. Use the copy panel for ChatGPT and Gemini Notebook.
      
        
      Who can use my agent?
      
        
      In Microsoft 365, people need a Copilot license and permission to any files you linked. Guests cannot use it in Teams chats. Gemini Skills may need a Google AI subscription, and Claude skills need a paid plan.
      
        
      How do I update an agent people already have?
      
        
      Open the file you downloaded before on the Home tab, make your changes, and download it again. For the Copilot app, keep the same file so the app id stays the same and the upload replaces the old version.
      
        
      Why does my agent not answer in a Teams chat?
      
        
      Agents from the Copilot app do not work in group chats, channels, or meeting chats. Use the .agent file in a SharePoint library and add it to the chat with Copy link for Teams.
      
        
      Is anything uploaded anywhere?
      
        
      No. Everything happens in your browser. The only thing the page loads from the internet is its own library of ready-made agents. Your draft is kept in this browser only, and you can clear it from the footer.
      
        
      How do I add my agent to the library?
      
        
      Download the complete copy, unzip it into the library folder, add one line to the catalog, and open a pull request. The add to the library page has the steps.
      
        
      What is a SKILL.md file?
      
        
      It is the open Agent Skills format: a Markdown file with a short header and the instructions underneath. Gemini and Claude both read it. See the Agent Skills specification.
