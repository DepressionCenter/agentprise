                                    Help

                                    What is Agentprise?

                                    Agentprise lets you describe an AI assistant or skill once, then download it for Copilot, Claude, Gemini, ChatGPT, Teams, and more.

                                    What are projects and skills?

                                    A project is one thing you are building, kept in your browser under Your projects on the Workspace page. Most projects hold one assistant. A project can also hold skills: sets of steps an assistant follows only when a question needs them, such as how to search PubMed. Choose Add a skill in a project to write one, or add one from the Library or a skill file, then check it under Skills it can use.

                                    Which download do I need?

                                    It depends on where people will use the assistant.

                                    • Copilot / Teams Apps gives you an app package (.zip) for the Agents list in the Microsoft 365 Copilot app and in Teams.
                                    • Teams Chat gives you a .agent file for a Teams group chat, channel, or meeting. You put the file in a SharePoint library first. Microsoft retires this file type after March 2027; see "How long will the Teams Chat file keep working?" below.
                                    • Gemini and Claude each get a skill (.zip) made for that product.
                                    • ChatGPT gets project instructions to paste into a ChatGPT project.
                                    • Claude plugin and Plugin hold the whole project, with its skills and tools. The Plugin works in ChatGPT, Codex, GitHub Copilot, Cursor, and OpenClaw.
                                    • SKILL.md gives you a plain skill (.zip) for Claude Code, Codex, Kimi Code CLI, OpenClaw, and other tools that read Agent Skills.
                                    • Gemini Notebook gets a .md file to add as a source, or the same text to paste.

                                    Not sure yet? Download a backup. You can come back any time and download it for another product.

                                    More Microsoft downloads

                                    These options need skills in Copilot or access to Copilot Cowork. Choose Review to read the changes and setup steps.

                                    • Copilot skill uploads one selected skill to an existing assistant. In Agent Builder, choose Configure, Skills, then Add.
                                    • Copilot app with skills (preview) keeps your assistant's skills separate so Copilot can use them when needed. Ask your admin to enable this feature. Add reference files to a skill.
                                    • Microsoft 365 plugin shares the whole project with Copilot Cowork. Assistants become optional skills and lose their assistant settings. Ask your admin to install the plugin.

                                    These downloads leave out scripts. Inspect lists other changes before you download. Keep a backup of your project. If your organization does not support these options, use Copilot / Teams Apps.

                                    Does it work with Kimi or OpenClaw?

                                    Partly. Kimi Code CLI and an OpenClaw you run yourself both read the SKILL.md download and the Plugin download, and OpenClaw also reads the Claude plugin. The Inspect page has the steps for each. Kimi chat, Kimi Agent mode, and the Kimi Claw that Kimi hosts for you have no way to upload a skill file yet, so Agentprise cannot make a download for them.

                                    What does "Download Backup" do?

                                    It saves the whole project, with every assistant, skill, and file, as one .zip file on your computer. Drop that file on the Workspace page later to open it again, change it, or download it for a different product. To upload to Gemini or Claude, use their own Download buttons instead.

                                    What are tools, and what does "needs setup" mean?

                                    Some assistants and skills, such as PubMed Search, can use a tool to look things up. Each product connects tools its own way, so every download lists what changes for it under "What changes in this download" on the Inspect page. "Needs setup" means one more step after you install, such as turning on a connector or pasting a server address. The setup steps that come with the download say how. If the tool isn't connected, the assistant does what it can and tells people it couldn't use the tool.

                                    Why is a download button grayed out?

                                    Either a required question is still empty, the product can't accept the project as it is, for example more than four web search sites for Copilot, or the author marked the assistant or skill as not for that product under More settings, then Products it works in. The Inspect page says what to change.

                                    Which files can I attach?

                                    Word, PowerPoint, Excel, PDF, OneNote (.one and .onepart), and plain text files, including scripts and data files such as PowerShell, Python, SQL, Markdown, CSV, and JSON. Up to 20 files, each under 10 MB. The app reads the start of every file and refuses programs, including ones renamed to look like a document. Copilot accepts only document types, .onepart, and .txt, so a script is added as a .txt file with the same name, and a .one file is left out of the app package. The skill .zip keeps every file under its real name.

                                    Where do links go?

                                    Each Copilot source has its own box under Copilot settings. Web sites go under Web search, up to 4. SharePoint and OneDrive links go under SharePoint and OneDrive, up to 20. Links to teams, channels, group chats, or meeting chats go under Teams messages, up to 5. Shared or group mailbox addresses go under Email. A box only matters while its source is on, and leaving it empty means Copilot may use everything the person can see.

                                    Who can use my assistant?

                                    In Microsoft 365, people need a Copilot license and permission to any files you linked. Guests cannot use it in Teams chats. Gemini skills may need a paid Google AI plan, and Claude skills need a paid Claude plan.

                                    How do I change an assistant I already shared?

                                    Open it from Your projects on the Workspace page, or drop the file you downloaded before on that page, make your changes, and download it again. For an app package, upload the new file in place of the old one. It keeps the same id, so Copilot treats it as an update.

                                    Why does my assistant not answer in a Teams chat?

                                    App packages do not work in group chats, channels, or meeting chats. Use the Teams Chat download instead: put the .agent file in a SharePoint library, choose Copy link for Teams, paste the link in the chat, and choose Add to this chat.

                                    How long will the Teams Chat file keep working?

                                    Until the end of March 2027. After that, .agent files stop answering in SharePoint, Teams chats, and the Copilot app. The Copilot / Teams Apps download continues to work.

                                    From mid-November 2026, you can choose Upgrade to Microsoft 365 agent in SharePoint. You need permission to edit the file and site pages, and to share agents. Ask the file owner or site owner if you need help. You can also create an agent in Copilot Agent Builder and copy your text into it.

                                    Keep the original file and an Agentprise backup until the replacement works. Agentprise can still open .agent files after retirement so you can recover their contents.

                                    Can I upload the .agent file to Copilot Agent Builder?

                                    No. Uploading a .agent file adds it as reference material. To create the assistant, start a new agent in Agent Builder. Copy the name, description, instructions, and example questions from Agentprise into the matching boxes, then choose the sources again.

                                    Why does Teams ask me to approve the answer?

                                    In a group chat, Teams shows the person who asked a preview whenever the answer used something the others may not be able to see, such as that person's own chats, mail, or meetings. Turn off Teams messages, email, and meetings under Copilot settings and answers post straight to the chat.

                                    What does the check for sensitive data look for?

                                    Before you download, the app looks through your assistant's text and plain-text files for things that often mean personal information, such as Social Security numbers, phone numbers, email addresses, street addresses, and dates labelled as a birth date or a hospital stay. It also looks for text that tries to take over an assistant, such as "ignore previous instructions" or invisible characters. If it finds something, a yellow box appears under Download. Choose View details to see where each match is, with the digits hidden. A match is a hint to look, not proof: a help desk assistant may list a phone number on purpose. It also misses plenty, including people's names, so it is not a privacy review and never blocks a download. The check runs in your browser and nothing is sent anywhere.

                                    Where does my work go?

                                    Nowhere. Your projects are kept only in your web browser and are never uploaded. Download a backup now and then, because browsers sometimes clear what they store.

                                    Can other people start from my assistant?

                                    Yes. The Library holds ready-made assistants anyone can try and change. To add yours, download a backup and send it to us on GitHub (opens in a new tab).
